# Security

## Reporting

Please report security issues privately through the repository owner or GitHub
security advisories if enabled. Do not open public issues for vulnerabilities.

## Sensitive Data Policy

Do not commit:

- foundry or PDK process files that are not explicitly redistributable
- Cadence, EMX, or license-server credentials
- tapeout layouts, extracted data, or proprietary design names
- personal usernames, hostnames, absolute workstation paths, or cluster account
  strings

Use placeholders or synthetic examples in public tests, docs, and workflows.
