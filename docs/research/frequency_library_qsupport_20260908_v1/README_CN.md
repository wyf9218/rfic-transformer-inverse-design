## 汇报应明确的结果

正式10K快照中，**5–20GHz全部16个频率的目标Q=20均超出各自STRICT训练标签的Q边际范围**，相应[19.5,20.5)邻域样本数均为0。5GHz的Q13..20、20GHz的Q10..11同样在观察范围之外。全部176格中54格标OUT；这是训练覆盖，不是物理可达性判决。

频率越高时本冻结严格训练子集明显缩小：5GHz为6015，15GHz为3175，20GHz为279。只描述本快照，不把该差别单独归因为模型准确率变化，不作跨频率因果排名。

整数q的局部计数使用[q−0.5,q+0.5)；宽度1只是事先固定的描述窗口，不是训练门禁或误差容差。每格百分比的分母是同频全部合格train，包括窗口外两尾。OUT独立由整数q是否位于train min/max确定，因此可能出现“计数>0但OUT”。正计数仅COUNT_ONLY，不表示充分支持。

没有使用val/test分布拟合窗口或normalizer，没有按Lp/Ls/|k|条件化；联合可达性仍UNKNOWN。全量冻结train计数不附伪IID置信区间。严格标签/SRF/2规则、原Q扫描和评分/容差均未更改。
