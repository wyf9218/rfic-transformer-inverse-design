# 15 GHz EuCAP：2026-09-09 已验证开发结果

本页公开两个已经独立核对的紧凑数表，不包含模型权重、原始几何或私有物理文件。三类实验必须分开：**6329来源几何的新模型开发验证、历史正式10K参考模型的原64物理试验、旧3018开发模型驱动的补样对照**。它们不是同一模型的连续精度成绩；本轮没有FINAL模型或最终10000请求结果。

## 1. 新6329数据：五结构、三seed

数据为6329个来源几何，固定分为3801 train、1269 validation、1259 test。旧3018成员的划分保持不变；所有结构共用新数据、hash划分和train-only normalizer。这里“6329”不是6329条均参加梯度训练。此次预测评价只使用1269条validation，test预测评价未运行。

已完成2×256、3×128、3×256、3×512、5×256五种隐藏层结构，各seed17/29/43，共15对、30个F/I角色。累计主实验更新538099次：复用原3×256 seed17的29600次，新增14对508499次；不含旧3018训练或隔离续训探针。每角色最大23757次更新，或按validation早停；训练收据仍为`PARTIAL`、`convergence=NOT_ESTABLISHED`。完成这一轮预算不等于证明充分收敛。

直接使用原字节表：[COMPARISON_5ROW.csv](eucap15_results_20260909/COMPARISON_5ROW.csv)（5行、29列）。

- `forward_parameters` / `inverse_parameters`是单角色参数量；`*_elapsed_seconds_mean/sd`是三seed角色耗时的均值/样本标准差，CPU每角色2线程。30角色耗时合计1653.4473475023406秒，不含评价、排队、打包，不是端到端成本。
- `ownF_*`是在相同validation既有EM标签上各自F的预测MAE/RMSE。Lp/Ls单位nH，Qmin和\|k\|无量纲；`Qmin=min(Qp,Qs)`。
- 所有I均使用同一个冻结的3×256 seed17基线F训练与评分；冻结F参数但保留几何输入梯度。因此`inverse_grid_*`是**共同F条件下的SELF_PROXY**，不是各自完整F/I系统的fresh EMX排名。
- `inverse_grid_joint_hit_rate_*`以每seed原1269个目标为分母，包含解析失败；数值是0–1比例，不是已乘100的百分数。四项均为对称目标匹配，固定跨度为[2.5, 2.5, 20, 0.8]；门限为各跨度的5%，不是目标相对误差5%。计算保留源浮点值。
- `_mean`和`_sd`为三seed统计量的均值与样本标准差，不是CI、合并目标分位数或总体精度区间；共同F训练随机性不包含在I的seed变化中。不得自动选“冠军”或作因果优越性归因。

这些新权重的fresh EMX尚未运行。15组best均已有真实validation加载评价；只有原新基线另有best/last加载及隔离续训证明，不能称新增14组全部通过last续训验收。

## 2. 原64物理试验：历史参考模型，不能改归新权重

原64使用历史正式10K参考`f15-strict_lumped-f5f2ced054ef`（10K为来源表标签，不是梯度训练行数），不是上述6329模型，也不是旧3018新训练模型。64请求全部终态：58个完成fresh EMX提取、4个GDS失败、2个原解析失败；58个中23个strict-valid、35个strict-invalid。35个invalid是SRF/2严格条件不满足，不能称为35次solver失败。

联合命中为**17/64=26.5625%**。17/23=73.9130%仅是严格有效子集内条件比例，不能代替原64分母。每请求只验证原先选定的一个候选，失败不替补；`q_emx=null`，未作完整11Q物理最优性审计。本页不重发原64原始行或重复运行其物理链。

定向臂16次中只有10个是指定物理目标的请求，其中2个strict-valid、1个strict联合命中；其余几何探索不具有该目标命中分母。DOE没有目标或q_proxy，目标误差及命中保持空值/不适用，而不是0%成功。

两臂16次是**以EMX准入为条件、相同已启动尝试数**的描述性对照，不是相同墙钟时间或相同端到端提案效率。原生耗时来自已保存日志值之和；wrapper时间仅为下界，未伪造原生PID出生时刻。新增样本和新增空格是不同终点：定向新增1空格、DOE新增4条train核心样本，不能概括成某臂全面更优。本轮无CI、无因果或总体优越性结论；没有把新物理行追加进已冻结6329训练数据。
