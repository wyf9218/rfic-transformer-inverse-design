## How to reuse safely

1. Read the experiment contract before running a script.
2. Use new no-clobber output directories.
3. Pass all data, model, executable, and host paths explicitly; never restore private defaults.
4. Keep raw EM labels separate from surrogate predictions.
5. Freeze target, split, architecture, decoder, training budget, seed list, and evaluation code before a controlled comparison.
6. Preserve every PASS/FAIL receipt and compute a manifest only after the complete artifact set is fixed.
7. Run public tests and inspect the generated SHA-256 repository manifest before committing results.

## What is intentionally absent

- real training tables and S-parameter files;
- model weights/checkpoints;
- production GDS/OASIS and foundry decks;
- Cadence/Calibre/EMX executables and licenses;
- private scheduler wrappers, hostnames, usernames, and absolute run paths;
- final result figures whose formal release interface is still NO-GO.

These omissions are deliberate security and research-integrity controls, not missing repository packaging work.
